连接与操作说明

先上传配套的 TangibleEarth.ino。关闭 Arduino IDE 的串口监视器，在桌面 Chrome 或 Edge 打开本页，再选择 Arduino Uno 的 USB 端口。相机可单独用 USB 供电。

相机联动时，汽车（ID 4）和电动吹叶机（ID 6）每次稳定识别后升温 20°F，舵机转 180°。自行车（ID 3）和手动除叶耙（ID 5）保持当前温度和舵机目标。汽车和吹叶机可以直接换着放。同一道具留在镜头里只触发一次，移开至少 1 秒再放回即可再次触发。现场需要接管时，点「仅手动」暂停识别联动。角度是 Uno 发出的舵机指令值。
